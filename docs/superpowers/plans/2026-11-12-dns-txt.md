# DNS TXT Codec Implementation Plan

> Use superpowers:executing-plans in this session.

**Goal:** Exact offline TXT RDATA fragmentation and UTF-8 reconstruction.
**Design:** [Contract and bounds](../specs/2026-11-12-dns-txt-design.md).
**Architecture:** Bounded pure TypeScript, Vapor view, five dictionaries/guides;
existing CodeInput, useToolExecution, ApplyControl and OutputActions. No package.

## 1. Codec

Files: `src/lib/tools/dns-txt.ts`, `.test.ts`, `dns-txt-sample.ts`.
- [ ] Write tests for 255/256 bytes, UTF-8 crossing fragments, exact escapes,
  empty/BOM/NUL, strict grammar, invalid UTF-8/surrogates and every cap.
- [ ] Observe RED with `pnpm test src/lib/tools/dns-txt.test.ts`.
- [ ] Implement `splitDnsTxt`, `restoreDnsTxt`, report and limits; rerun GREEN.

## 2. Integrated workflow

Files: `DnsTxtTool.vue`, `.test.ts`, `src/i18n/dns-txt.ts`, guide and registries;
README, overlap/testing documentation, `docs/dns-txt.md`.
Review fixes also touch CodeInput and the shared reader/worker transport:
opt-in BOM retention and rejection after async empty fallback, with real
reader/worker/drop regression tests; defaults for other tools remain.
- [ ] Test real Vapor before implementation: both modes, intentional empty
  value, rejected edits, explicit exact copy, deferred/manual/cancel/disposal,
  all locales and remount clearing.
- [ ] Implement one `dns-txt` network tool and localized static guides.
- [ ] Run typecheck, lint and units; document strict subset and tool caps.

## 3. Verification and delivery

Files: production/public `dns-txt.spec.ts`, synthetic screenshots.
- [ ] Four-project/five-locale/theme operation, keyboard/mobile, downloads,
  boundary errors, delayed/manual/cancel, lifecycle and asset/privacy audit.
- [ ] Capture and inspect synthetic desktop/small screenshots.
- [ ] Commit final code, run applicable complete local quality gates and
  targeted four-project E2E; independent immutable-diff review and fixes.
- [ ] Push own branch; draft PR with purpose/use/scope/limits/evidence/images.
  Full final-head browser CI, review conditions and current-main recheck;
  ready and ordinary merge guarded by exact head SHA.
- [ ] Verify merged main tree, quality/deploy/public jobs and live Pages.

Review focus: byte vs code-point boundaries, UTF-8 BOM/fatal decode, decimal
escape semantics, misleading concatenation across records, zero-length
outputs, stale exports after rejected edits and memory/network lifecycle.
