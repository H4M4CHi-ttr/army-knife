# IDN Inspector Implementation Plan

> **For agentic workers:** Execute inline with superpowers:executing-plans; obtain one independent whole-branch review.

**Goal:** Compare Unicode/ASCII domain labels and code points without DNS or network access.
**Architecture:** Bounded TypeScript host mapping and Punycode decoding; existing Vapor input/execution/export controls and localized guides.
**Tech Stack:** Existing Vite+, Vue 3.6 RC/Vapor, shadcn-vue, TypeScript.
**Spec:** `docs/idn.md`

## Global Constraints

- Only H4M4CHi-ttr/army-knife. Preserve mounted empty repository and #145/#149.
- No added dependency, runtime request, input persistence, telemetry or configuration changes.
- 2 KiB input; 63-byte labels; 253-byte domain excluding root; 127 labels.
- Up to 128 UTF-16 units instant; otherwise 800ms/manual/cancel waiting.
- Five languages, keyboard/mobile/themes, final-head CI and normal merge/Pages.

## Review Focus

- IP-like numeric hosts and URL syntax must never be interpreted as domains.
- A-label decoding must round-trip; malformed labels yield no partial output.
- Mapping may change input; Unicode output must be labeled as normalized.
- Script heuristics must not imply safety or comprehensive confusable detection.
- Rejected edits, pending work and navigation must remove old exports.

## Review resolution

Independent read-only review of `30068160..97e449f2` found two Important defects:
whole-label URL round trips misread non-final numeric labels as IPv4; inherited
file drop behavior left old exports during an asynchronous file read. Numeric
round trips now apply only to decoded A-labels, with four failing-then-passing
vectors. This view rejects file drops in capture phase without reading them,
with a failing-then-passing stale-result regression and browser coverage. No
Critical or Minor findings. Documented non-goals from the review remain the
specification's explicit scope, rather than incomplete delivered functionality.
