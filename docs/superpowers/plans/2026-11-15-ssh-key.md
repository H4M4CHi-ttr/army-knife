# SSH public-key inspector Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Inspect one SSH public-key line and compare its SHA-256 fingerprint offline.

**Architecture:** A bounded TypeScript SSH-wire reader feeds a native Web Crypto
digest with timeout/cancellation disposal. One Vapor view uses the existing
execution/input/output controls, catalogue, translations and static guides.

**Tech Stack:** Existing Vite+ 1.1.0, Vue 3.6.0-rc.11/Vapor, shadcn-vue,
Web Crypto, Vite+ tests, Chromium/Firefox Playwright. No new dependency.

**Spec:** docs/superpowers/specs/2026-11-15-ssh-key-design.md

## Global Constraints

- Change only H4M4CHi-ttr/army-knife, isolated branch from main915e6a0.
- Key input 16 KiB UTF-8; decoded blob 4 KiB; comment 4 KiB; RSA exponent 256 bytes.
- Reference input 128 raw UTF-8 bytes; complete JSON output 32 KiB.
- Exactly Ed25519/RSA/ECDSA nistp256/384/521; uncompressed EC points only.
- Five languages, both themes, existing Noto/Sarasa/licensing and preference policy.
- Immediate through 2,048 UTF-16 units, otherwise existing 800 ms/manual/cancel.
- Native digest timeout 5,000 ms; abort stops waiting and discards late results.
- No input/result network, URL/storage/log persistence, dependencies or WebMCP.
- No key generation, SSH connections, mathematical validation or trust claims.
- No #169/#145 edits, force/admin/protection/billing/credential/hosting changes.

## Review Focus

- Declared uint32 string lengths/trailing bytes: bounded failure with no allocation or partial report (Task 1).
- Mathematical-invalid but structurally-shaped material: clearly bounded inspection rather than a trust/acceptance claim (Tasks 1/2).
- Comments containing markup, directional text and URL-like data: inert, visibly escaped and never requested (Tasks 1/3).
- A rejected reference edit/import after success: no stale fingerprint/JSON exports (Tasks 2/3).
- Native digest settles after abort/navigation or deadline: no late output, leaked timer/listener or unhandled rejection (Tasks 1/2).
