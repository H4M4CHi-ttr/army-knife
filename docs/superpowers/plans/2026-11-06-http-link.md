# HTTP Link Inspector Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans, then an independent review.

**Goal:** Inspect recorded Link field structure and pagination relations locally.
**Architecture:** Bounded pure TypeScript scanner, one Vapor view, catalog/i18n/static-guide registration. Reuse shared execution/input/export controls.
**Tech Stack:** Existing Vue 3.6 RC/Vapor, Vite+, TypeScript; no new packages.
**Spec:** `docs/superpowers/specs/2026-11-06-http-link-design.md`.

## Global constraints

- UTF-8 8 KiB / 32 links / 64 slots / 32 parameters per link; no partial reports.
- Immediate through 2,048 units, then existing 800ms/manual/cancel controls.
- Raw unresolved targets and opaque attributes; no network, persistence or active links.
- Five languages and existing distribution/license policy.

## Review focus

Commas and semicolons inside targets/quotes must not split links. Escaped quotes
must not end values. Missing/duplicate rel must not invent relations. Valueless
and empty attributes must remain distinct. Rejected or delayed edits must remove
previous exports. Each is pinned by parser or real-view/browser tests below.
