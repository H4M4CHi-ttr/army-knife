# Dockerイメージ参照検査（2026-11-04 JST）

名前付きDockerイメージ参照を貼り付け、レジストリ・ホスト・指定ポート・
リポジトリパス・タグ・digestを確認します。通信やDockerコマンドの実行はしません。

例：`alpine` → `docker.io/library/alpine:latest`。省略したレジストリ、
`library/`、`latest`を個別に表示します。
`registry.example:5000/team/app:stable@sha256:`に64桁の小文字16進数を続けた
参照では、指定タグを保持した表記と、タグを除いてdigestを選択するpull用表記を
並べます。タグとdigestが同じ内容を指すかは確認しません。

1. 名前付きイメージ参照を1件入力、または合成データの「例を読み込む」を実行します。
2. 省略値、タグの可変性、digest優先を確認します。許容範囲の編集は即時反映します。
3. 必要なときだけJSONをコピー・保存します。クリア・画面移動・言語変更・再読込で
   入力と結果を消去します。

## 対応範囲と制約

- 生入力は外側のASCII空白・タブを除く前でUTF-8 **1 KiB**まで。内部空白、改行、
  制御文字、Unicode空白、URL、コマンド、複数参照は拒否します。
- 正規化後のリポジトリパスは**255文字**まで（補完した`library/`を含み、
  レジストリ・タグ・digestを除く）。小文字ASCII英数字の要素を`/`で結び、
  要素内ではドット1個、下線1〜2個、連続ハイフンを英数字間に使用できます。
- タグは**1〜128文字**。ASCII英数字・下線で始まり、以降は英数字・下線・
  ドット・ハイフン。大文字小文字を保持し、勝手に小文字化しません。
- `/`より前の要素が`localhost`、ドット・コロンを含む、または大文字を含む場合は
  レジストリです。`registry/app`はDocker Hubのパス、`Registry/app`は指定
  レジストリです。`example.com`単独もDocker Hubのリポジトリとして扱います。
  `localhost:5000`単独は名前`localhost`・タグ`5000`で、ホスト指定には`/`が必要です。
- 正確に小文字の`index.docker.io`だけを`docker.io`へ変換します。正確に
  `docker.io`でパスが1要素の場合だけ`library/`を補完します。
  レジストリの大文字小文字やポートの先頭ゼロを保持します。ホストは命名構文の
  確認のみでDNS・IP到達性やポートの数値範囲は検証しません。
- 角括弧IPv6のグループ構造を確認します。ゾーン識別子・IPv4混在表記は未対応。
  DistributionのIPv6正規表現より厳格で、不正な`[::::]`等は拒否します。
- digestは小文字の`sha256:`＋**64桁**、`sha512:`＋**128桁**の小文字16進数のみ。
  他のアルゴリズムは「未対応」とし、一般的な無効性を断定しません。
  digestを計算したり、イメージ内容と照合したりしません。
- 単独の64桁小文字16進ID、単独のSHA-256/SHA-512 digestは拒否します。
  短い`abc123`などは名前として扱い、ローカルイメージIDを推定しません。
- `latest`はタグ・digestの両方がない場合だけ補完。digest単独付きの参照には
  タグを追加しません。タグ併記は保持して明示し、pull時はdigestを優先します。
- タグは内容が変わる場合があります。指定digestも未検証で、存在、取得内容、
  プラットフォーム、署名・信頼性・安全性は判定しません。マルチプラットフォーム
  manifestのdigestだけでは1つのプラットフォームを指定しません。

上限以内の処理は軽いため、共有実行コントロールの即時モードを使用します。
自動適用をオフにしていても即時です。Worker・重処理・遅延実行はありません。
エラー・サイズ超過の編集時には古い結果と出力操作を即座に消し、部分結果を返しません。

入力・結果はメモリ内のみ。入力データをURL・永続ストレージ・ログ・通信へ保存・
送信せず、入力からリンクやコマンドを生成しません。外部API・新規依存は追加しません。
5言語・ライト／ダークテーマ・キーボード・狭幅表示・明示JSON保存に対応します。

## 一次資料と重複方針

[Dockerの名前付けドキュメント](https://docs.docker.com/reference/cli/docker/image/tag/)と
[Distribution referenceの定義](https://github.com/distribution/reference/tree/0965666a6ade2e06035fe352e38344be1e68951a)
（`regexp.go`、`normalize.go`、`reference.go`）を2026-11-04 JSTに確認しました。
TypeScriptで独立に実装し、上流ソースコードや実行時ライブラリは取り込んでいません。
これは対応範囲を限定した構文検査で、Docker CLI全般・OCI文書全般の検証ではありません。

[DevToys公式バンドル一覧](https://devtoys.app/)に専用のイメージ参照検査がないため
既定オンです。コミュニティ拡張は比較対象に含めません。

## 検証

純粋関数テストでは省略値・明示値・レジストリ判別・別名・大文字小文字・ポート・
IPv6・タグとdigestの優先関係・長さ境界・未対応アルゴリズム・不正入力を確認します。
実Vaporテストでは即時更新・JSONコピー・拒否編集による無効化・同じ例での復帰・
5言語の正常／エラー描画・再マウント時の破棄を確認します。
専用E2EはChromium/Firefoxのデスクトップ／390px幅で、5言語、両テーマ、キーボード、
正確なJSONダウンロード、画面移動・再読込・言語変更、厳密な配布物パスの通信監査を
実行します。スクリーンショットは予約ドメインと合成digestのみです。
