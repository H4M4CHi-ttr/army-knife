# DNS TXT分割・復元

長い検証値やSPF/DKIM向けテキストを、DNS TXTの255データオクテット以下の
引用断片へ分割します。復元モードでは1件のTXT RDATAを入力し、断片のバイトを
空白追加なしで連結してUTF-8テキストへ戻します。DNS照会・設定変更は行いません。

「テキスト → TXT断片」で値を入力し、正規表記のRDATAを明示コピー・保存します。
「TXT断片 → テキスト」はモード変更時に入力を消し、引用RDATAを受け付けます。
空文字は有効な1断片 `""` です。初期状態とクリア後は結果を表示せず、入力を
明示的に空へ編集すると分割結果として扱います。復元で空の入力は不正です。
引用RDATAと復元テキストは別々に全文をコピー・保存できます。

サンプルは `verification=` と241個の `x` と `あ` からなる257バイトです。
255・2バイトに分かれ、末尾は `\227` と `\129\130` になります。
個別断片を文字列へ復号せず、全バイト連結後に復号するため文字を壊しません。
文字データ257バイト、長さオクテット2個込みのRDATAは259バイトです。
後者は所有者名・RRヘッダー・DNSパケット全体のサイズではありません。

## 受け付ける範囲

- 分割：加工前UTF-8 **8 KiB**。不正なUTF-16サロゲートは置換せず拒否。
- 復元：加工前RDATA **64 KiB**、**64断片**（空も数える）、
  各断片 **255データオクテット**、連結データ **8 KiB**。
- 引用符付きASCII断片を空白・タブで区切ります。複数行の断片には外側の
  括弧1組が必要です。前後のASCII空白・タブ・CR・LFは許容します。
- `\"` と `\\` は引用符とバックスラッシュ。`\DDD` は000〜255の10進数3桁。
  数字以外の印字可能ASCIIの引用は1回だけ解釈します。`\n` は文字 `n` です。
- 生成時は印字可能ASCII以外を10進オクテットで表現します。復元時の引用内は
  生の改行・制御文字・非ASCIIを受け付けません。UTF-8は厳密に検証しBOMも保持。
- 断片境界を復元結果の正規RDATAにも保持します。空白の挿入、Unicode正規化、
  BOM削除、切り詰めはしません。エラー時は部分結果・古い出力を表示しません。

1 KiB = 1024バイト。これらは本ツール独自の上限で、DNS全体の最大値では
ありません。DNS TXT自体はバイナリも許しますが、このツールはUTF-8専用です。
所有者名・TTL・クラス・TXTキーワード、コメント、非引用文字列、入れ子括弧、
複数RR、ゾーン全体は対象外です。SPF/DKIMの意味や公開可能性は検証しません。
任意のTXT用途で連結が意味を持つとは限らず、DNS事業者のフォームが要求する
引用方式も確認してください。全ゾーンとSPF/DMARC検査のIssue #61/#62は別範囲です。

## 実行とデータ

2048 UTF-16コード単位以下は自動適用オフでも即時反映します。それ以上は
既存の800ms待機・手動適用・待機中止を使います。処理開始後の同期計算は
中断できませんが、入力・出力を小さく制限しています。全断片を表示します。
キーボード、390px幅、ライト・ダーク、日英中簡体・繁体・韓国語に対応します。

入力・結果はコンポーネントのメモリ内のみ。ツール・言語変更と再読み込みで
破棄します。入力欄へ明示ドロップしたUTF-8ファイルは既存CodeInputがローカルで
読み込みます。コピーと保存は明示操作だけで、送信、入力のURL化・永続化、
新規依存・テレメトリ・外部フォント・WebMCP・公開設定の追加はありません。

## 根拠と検証

[RFC 1035 §§3.3, 3.3.14, 5.1](https://www.rfc-editor.org/rfc/rfc1035.html)の
長さ付き文字列・TXT RDATA・マスターファイル表記に基づく限定コーデックです。
[RFC 7208 §3.3](https://www.rfc-editor.org/rfc/rfc7208.html#section-3.3)のSPF用途も
踏まえ、連結時に空白を追加しません。RFC全文の実装やメール認証検証ではありません。

純粋関数で境界・不正入力・全上限、実Vaporで空値・モード・遅延・手動・中止・
拒否編集・明示コピー・5言語・破棄を検査します。production E2Eは4ブラウザー
プロジェクトで5言語・両テーマ・キーボード・ダウンロード・公開物だけの通信・
URL/Storageへの入力漏洩を検査し、既存Pages公開後も同じ操作を確認します。
